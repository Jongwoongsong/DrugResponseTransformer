Cell-blind split manifests

Cell-line identities were partitioned before assigning GDSC response rows.
The fixed split contains 776 training, 97 validation, and 97 test cell lines,
corresponding to 332,414 / 42,000 / 41,257 retained response measurements.

Only cell identifiers are redistributed here. GDSC LN_IC50 response values are
not included in these public manifests.

For the final cell-blind analysis, basal-expression harmonization statistics
were estimated from the 776 training cell lines and then applied to validation
and test cell lines.
